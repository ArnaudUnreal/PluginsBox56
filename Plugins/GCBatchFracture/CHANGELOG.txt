- Fracture : les sites Voronoi sont générés dans la bounding box de chaque morceau sélectionné ; les niveaux > 0 découpent réellement les petits morceaux.
- Un niveau > 0 qui ne crée aucun morceau est ignoré et signalé "LIMITED", au lieu de faire échouer l'asset.
- Correctif bloquant : fracture infinie en UE 5.6/5.7. L'échantillonnage de collision n'est envoyé au moteur que si bAddSamplesForCollision est coché.
- CollisionSampleSpacing : 50 cm par défaut, minimum 1 cm, éditable seulement si bAddSamplesForCollision est coché.
- La fracture tourne sur un thread de travail : l'éditeur reste réactif et Cancel répond pendant le traitement.
- Annulation possible entre chaque étape d'un asset : l'asset en cours est jeté, l'annulation est notifiée et écrite dans l'Output Log.
- Un second batch ne peut pas démarrer pendant qu'un batch est en cours.
- Un asset dont la fracture ou la sauvegarde échoue est supprimé : plus d'asset cassé dans le Content Browser.
- Notification de fin de batch (créés / ignorés / échecs / limités) avec lien vers l'Output Log, où les raisons d'échec sont détaillées.
- Message d'échec de validation du mesh plus précis.
- Complexité vérifiée avant création : plus de dossier GC/ vide. Pour les meshes Nanite, la géométrie source pleine résolution est comptée.
- MaxSourceTriangles : 200 000 par défaut (0 = désactivé). Une valeur déjà enregistrée dans un .ini reste prioritaire.
- Menu contextuel plus léger : les Static Meshes ne sont chargés qu'au lancement de l'action.
- Avertissement "non-overlapping convex hulls" affiché uniquement avec le preset Custom.
- Valeurs par défaut alignées sur le preset Balanced.
- Settings enregistrés par utilisateur (Saved/Config) : Config/DefaultEditorPerProjectUserSettings.ini n'est plus réécrit. Section affichée dans Project Settings > Plugins.
- Compatible UE 5.6, 5.7 et 5.8 (Win64).
